# AI Clipper — Design System

## 1. Identity
A modern, premium, professional editing-tool interface — think professional SaaS dashboard, not a generic AI-template look.

- **Background:** dark charcoal
- **Primary accent:** purple
- **Typography:** clean, modern sans-serif
- **Shapes:** rounded cards, modern icons
- **Motion:** minimal, meaningful animations only
- **Layout:** proper spacing, fully responsive

### Avoid
- Excessive gradients
- Unnecessary animations
- Cluttered layouts
- Generic "AI-generated-looking" dashboards
- Overly complicated navigation

## 2. Navigation (Main Sidebar)
1. Dashboard
2. New Project
3. My Projects
4. AI Clip Generator
5. Caption Studio
6. Music Library
7. Export History
8. Settings

## 3. Dashboard
Shows: total projects, total clips generated, recent projects, recent exports, processing activity, project status, and a "Create New Project" button.
Use real database values once DB integration exists — never show fabricated sample numbers as real data.

## 4. New Project Workflow
1. Enter project name
2. Select content category
3. Upload video or provide authorized source
4. Configure clip duration
5. Configure highlight preferences
6. Start processing

## 5. Editor Interface (eventual)
- Video preview player
- Timeline
- Generated clips list
- Caption controls
- Music controls
- Aspect ratio settings
- Export settings

## 6. Caption Presets
Separate visual presets tuned per category:
- **Gaming** — bold, high-energy styling
- **Podcast** — clean, readable, minimal-distraction styling
- **Sports** — dynamic, scoreboard-adjacent styling

All presets must remain readable on mobile screens.

## 7. Design Principles
- Every screen should feel intentional — no filler UI.
- Consistency in spacing, color usage, and iconography across all pages.
- Prioritize clarity for a beginner-friendly workflow without feeling "dumbed down."
